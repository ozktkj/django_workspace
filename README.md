## psysアプリケーション
### プロトタイプ１
- 得意先検索機能(得意先コードで1件を絞り込む)
- ログイン機能(従業員テーブルでログイン処理)
- メインメニュー
- ログアウト機能(仕様にはないが動作確認用)

### プロトタイプ2
- 得意先追加(採番テーブルに注意)
- 得意先一覧
- 得意先削除(論理削除に注意)
- 得意先変更

## DBの復元について
CドライブのMySQLが再起動リセットされるため、バックアップコマンドを用意した。

|コマンド名|役割|備考|
|---|---|---|
|backup.bat|バックアップを作成|mysql_backupディレクトリにpsysdb3.sqlを作成|
|restore.bat|復元を実行|DBの復元、ユーザーの復元、権限の復元を行う|

`mysql_backup/user_create.sql`と`mysql_backup/user_grant.sql`は各自編集してください。
